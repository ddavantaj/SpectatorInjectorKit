[ 1.1 UNIVERSAL COMPATIBILITY ]
--------------------------------------------------------------------------------
This suite works with ANY Unity VR / Mixed Reality game build on Windows:
- OpenXR, Meta / Oculus XR SDK, SteamVR, XR Interaction Toolkit.
- Automatically creates a dedicated PC spectator camera if the game doesn't have one!

[ 1.2 QUICK INSTALLATION (1-CLICK INJECTOR) ]
--------------------------------------------------------------------------------
1. Open the SpectatorInjectorKit folder.
2. Double-click "Inject.bat" (or "InjectSpectatorCamera.exe").
3. Select any Unity game build directory (where the game .exe is located).
4. The patcher automatically injects "SpectatorPlugin.dll" and bundles "ffmpeg.exe".
5. Launch the game executable. The Universal Spectator overlay will appear automatically.

[ 1.3 3 VR CAMERA TRACKING MODES ]
--------------------------------------------------------------------------------
- 🎯 1st Person (1:1 VR)      : Real-time 1:1 tracking of the player's VR headset.
- 🎥 3rd Person (Shoulder)    : Cinematic over-the-shoulder drone follow with
                               adjustable distance (0.5m - 6.0m) and height (-0.5m - 2.5m).
- 🛸 Free Flight (World)      : Complete 3D freedom in world space with WASD + Mouse Look.

[ 1.4 KEYBOARD SHORTCUTS & CONTROLS ]
--------------------------------------------------------------------------------
- F1             : Toggle Spectator UI on / off
- F9             : Capture Screenshot (Alpha PNG / 8x MSAA)
- F10            : Toggle Screen Recording (Zero-Lag 60 FPS MP4, 1:1 Real-Time)
- W / A / S / D  : Move Camera Forward / Left / Backward / Right in World Space
- E / Space      : Fly Upwards in World Space
- Q / Left Ctrl  : Fly Downwards in World Space
- Left Shift     : Hold for Fast Speed Boost (Turbo)
- Right-Click    : Hold & Drag mouse to Look Around / Orbit (Pitch & Yaw)

[ 2.1 COMPATIBILITATE UNIVERSALĂ ]

[ 2.2 INSTALARE RAPIDĂ (INJECTOR UNIVERSAL 1-CLICK) ]
--------------------------------------------------------------------------------

2. Rulați "Inject.bat" (sau "InjectSpectatorCamera.exe").

4. Injectorul va insera automat "SpectatorPlugin.dll" și "ffmpeg.exe".
5. Porniți jocul. Camera Spectator va apărea direct pe ecranul monitorului PC.

                               (0.5m - 6.0m) și înălțime (-0.5m - 2.5m).

[ 2.4 SCURTĂTURI DE TASTATURĂ ]
